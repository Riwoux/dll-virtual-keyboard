# Contributing to Virtual Keyboard DLL

**[English](#english) | [Français](#français)**

---

## English

Thank you for your interest in contributing to the Virtual Keyboard DLL project! We welcome contributions from the community.

### How to Contribute

#### Reporting Bugs

If you find a bug, please create an issue with:
- A clear and descriptive title
- Steps to reproduce the problem
- Expected behavior
- Actual behavior
- Your environment (Windows version, C++ Builder version)
- Screenshots if applicable

#### Suggesting Features

We're open to new ideas! Please create an issue with:
- A clear description of the feature
- Why this feature would be useful
- Possible implementation approaches (if you have ideas)

#### Submitting Pull Requests

1. **Fork** the repository
2. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** following our coding standards (see below)
4. **Test your changes** thoroughly
5. **Commit your changes** with clear commit messages
6. **Push** to your fork
7. **Create a Pull Request** with a clear description of your changes

### Coding Standards

- Follow the existing code style
- Use meaningful variable and function names
- Comment complex logic
- Keep functions focused and small
- Use C++ Builder VCL conventions

### Development Setup

1. Install C++ Builder 13 (RAD Studio 12 Athens) or compatible version
2. Clone the repository
3. Open the `.cbproj` files in C++ Builder
4. Build the projects

### Questions?

If you have questions, feel free to:
- Open an issue for discussion
- Contact the maintainers

## Français

Merci de votre intérêt pour contribuer au projet Virtual Keyboard DLL ! Nous accueillons les contributions de la communauté.

### Comment Contribuer

#### Signaler des Bugs

Si vous trouvez un bug, veuillez créer une issue avec :
- Un titre clair et descriptif
- Les étapes pour reproduire le problème
- Le comportement attendu
- Le comportement réel
- Votre environnement (version Windows, version C++ Builder)
- Des captures d'écran si applicable

#### Suggérer des Fonctionnalités

Nous sommes ouverts aux nouvelles idées ! Veuillez créer une issue avec :
- Une description claire de la fonctionnalité
- Pourquoi cette fonctionnalité serait utile
- Des approches d'implémentation possibles (si vous avez des idées)

#### Soumettre des Pull Requests

1. **Forker** le dépôt
2. **Créer une branche** pour votre fonctionnalité ou correction :
   ```bash
   git checkout -b feature/nom-de-votre-fonctionnalite
   ```
3. **Faire vos modifications** en suivant nos standards de code (voir ci-dessous)
4. **Tester vos modifications** minutieusement
5. **Commiter vos modifications** avec des messages de commit clairs
6. **Pousser** vers votre fork
7. **Créer une Pull Request** avec une description claire de vos modifications

- Suivre le style de code existant
- Utiliser des noms de variables et de fonctions significatifs

- Garder les fonctions focalisées et petites
- Utiliser les conventions VCL de C++ Builder

### Configuration du Développement

1. Installer C++ Builder 13 (RAD Studio 12 Athens) ou version compatible
2. Cloner le dépôt
3. Ouvrir les fichiers `.cbproj` dans C++ Builder
4. Compiler les projets
